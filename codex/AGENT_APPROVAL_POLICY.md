# エージェントの承認・本人操作・継続方針

2026-11-01。スマホのチャットから承認し、Codexが許可された実操作と検証を完了するための共通運用。repo文書による一律の本人PC操作・重複承認を置き換える。稼働中の認証、権限、承認UI、監査、安全機構を変更する文書ではない。

## 承認と実操作を分ける

- 利用者の具体的な依頼・承認に含まれる対象、操作、権限、影響範囲を確認し、その範囲の準備・実行・読戻し・結果報告までCodexが進める。同じ作業を工程名、repo、ブラウザ、会話の再開だけを理由に再承認待ちにしない。
- 本人が承認を判断することと、本人がPC上でクリックすることは別である。アカウント選択、通常のサインイン、OAuth同意、API有効化、公開・配備の操作も、具体的承認と使用ツールの規則が許せばCodexが行う。スマホからのチャット承認を本人PC操作へ置き換えない。
- 実行時の追加承認が必要なら、先に承認に依存しない調査・準備・検証を済ませ、対象アカウント/アプリ、実際の権限、操作、影響、既承認との差分を具体化してチャットで尋ねる。Googleの広いDrive scopeを、コード上の固定フォルダ制限と同じ範囲の権限だと説明しない。利用規約への同意も、必要な内容を示して本人の判断を受ける。
- 新しいscope、別アカウント/対象、費用・公開範囲の拡大、未承認の破壊的操作、承認期限切れ・撤回は既承認に含めない。明示的な停止指示は解除されるまで守る。過去の承認記録だけを無関係な作業の包括許可にしない。
- 「実行時に別承認」「承認後」と書かれた手順は、現在の具体的依頼ですでに満たされているか確認する。単なる設計合意を本番承認へ読み替えず、実際に承認済みなら同じ質問を繰り返さない。

## 上位規則とrepo独自規則

| 根拠 | 扱い |
| --- | --- |
| system/developer・使用ツールの必須確認や本人操作、プラットフォームの安全停止 | 常に従う。repo文書やチャット承認で解除できない。実行時の専用承認UIが必須なら、その手続きを使う |
| 本人のみが完了できる追加認証・端末操作 | 画面と必要操作だけを引き継ぐ。可能ならスマホの認証で継続し、秘密値をチャットへ要求しない |
| repoが一律に定めた「OAuthは本人がクリック」「毎工程で承認」「全作業を停止」 | 本方針に従い、承認内容と実操作能力で判断する。本人操作が必須という上位規則のように説明しない |
| 実システムの認証・現在のgrant/ACL/IAM、重複防止、読戻し契約 | 維持する。承認済みでも検査・署名検証・単回実行・結果照会を省略しない |

必須確認や本人操作を依頼するときは、該当するツール規則・画面要求・文書と、なぜ必要かを明示する。自動承認レビューが拒否した場合は、その操作と理由を報告し、別経路で迂回しない。影響しない文書準備・検証などは続ける。

## スマホから継続する

- 既存の有効なセッションと接続先を確認して利用する。本人・対象・権限の確認は、実際に操作するサービスと経路で行う。別ブラウザのログイン成功を代用しない一方、同じ確認のためだけに複数ブラウザへログインしない。
- GitHub文書の編集・レビューやオフライン検証には、関係しない本番サービスのログインや全画面スタンバイを要求しない。本番操作が必要になった時点でその対象の本人・接続先を確認する。
- ブラウザが使えない場合は[共通起動手順の復旧](CODEX_DESKTOP_STARTUP.md#mobile-origin-browser-recovery)に従う。本人へのPC操作、PC/アプリ再起動、再インストールを最初の解決策にしない。復旧できない場合も、必要な本人操作と残る独立作業を分ける。
- パスワード、OTP/MFA、CAPTCHA、端末の本人確認など、使用ツールの規則または実際の画面が本人操作を必要とする手続きだけを引き継ぐ。認証を弱めたり、cookie/token/認証JSONをコピーして回避したりしない。
- 実スマホの音声・添付などの受入が必要な場合は、その機器・モードの確認だけを依頼する。PCでの成功を実スマホ受入済みと扱わない。

## 一回の実行と証拠

承認済みでも、完了済みのmigration、認可、配備、送信を繰り返さない。再開時は現状と承認範囲を照合し、未完了部分だけ進める。結果不明なら元の識別子・受付・設定を読取りで照会し、新ID発行や再送で解決しない。停止は影響を受ける操作・対象に限定し、依存しない作業を継続する。

記録するのは承認対象の非秘密の要約、実施/未実施、読戻し・検証結果、GitHub上の証拠参照だけとする。秘密値、OAuthコード、token、認証JSON、`.env`内容、認証中のURL、生ログを保存しない。GitHub反映と本番反映、ユーザー報告と直接観測を区別する。
